# Meu Study Hub - Ciência da Computação 🚀

Repositório estratégico desenvolvido no último semestre para consolidar, organizar e documentar os conhecimentos adquiridos na graduação.

## 🔗 Links Rápidos
* **GitHub Pages:** https://atsocd.github.io/Meu_Study_Hub_TI/

## 🤖 Integração e Apoio com IA (Google GEMINI)
A implantação, arquitetura de versionamento e definição das diretrizes de segurança deste repositório foram orientadas e validadas com o auxílio do **Google GEMINI**, garantindo a aplicação de melhores práticas de desenvolvimento, gestão de usuários e controle de acesso.

## 🛡️ Gestão e Segurança
* **Políticas de Segurança:** Arquivo `SECURITY.md` configurado.
* **Controle de Acesso:** Definição de regras via `.github/CODEOWNERS`.
* **Versionamento:** Controle de versão com Git/GitHub e implantação contínua via GitHub Pages.

## 📁 Estrutura de Diretórios
* `01_Apresentacao_e_Perfil/`: Apresentação acadêmica e profissional.
* `02_Disciplinas_Atuais/`: Atividades de Bootcamp I, Projeto Integrador IV, Segurança Digital, Testes e Sistemas Embarcados.
* `03_Projetos_e_Certificados/`: Projetos pessoais e certificados.

## 🛠️ Tecnologias Utilizadas
* Git e GitHub para versionamento e documentação.
* HTML5 / GitHub Pages para hospedagem estática.
