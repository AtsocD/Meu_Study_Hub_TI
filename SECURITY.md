# Política de Segurança - PortfolioHUB

## Versões Suportadas
Projetos e serviços ativos no repositório com suporte a correções de segurança:

| Versão | Suportado          |
| ------ | ------------------ |
| 1.0.x  | :white_check_mark: |

## Reportando Vulnerabilidades
Para reportar problemas de segurança ou vulnerabilidades encontradas neste repositório:
1. Abra uma issue privada ou entre em contato com o mantenedor do repositório.
2. Descreva os detalhes do problema e passos para reprodução.

## Boas Práticas Implementadas
- Revisão de código com apoio da IA Google GEMINI.
- Bloqueio de credenciais e chaves expostas no código.
- Uso de permissões mínimas necessárias para controle de acesso.
